👋 Welcome to the Admin Panel

Use the sidebar on the left to manage students, teachers, content, attendance, tests, and live classes.

➕ Add New Student Account

Create login credentials for a new student. Share the Student ID and password with them directly.

Student ID format: Use a consistent format like NTC-2026-001 (Year + 3-digit number). The student will use this ID (not email) to log in.

Pick only the subjects this student is enrolled in. They'll be shown as tags on the student card.

Controls which extra content the student can see. Normal = class content only. Class 10: Normal / Foundation. Class 11–12: Normal / JEE / NEET.

📥 Bulk Import Students (XLSX / CSV)

Upload a spreadsheet to create many student accounts at once. Existing accounts are skipped automatically. Required columns: Student ID, Password, Student Name, Class, Board, Subjects, Enrollment Type, Parent Phone.
Subjects is a semicolon- or comma-separated list (e.g. Physics;Chemistry;Maths). Enrollment Type is one of normal / foundation / jee / neet.

🔑 Reset Student Password

Enter the Student ID and set a new password for that account.

🧹 Remove old stored passwords

Earlier versions saved each student's and teacher's password in plaintext in the database. That is no longer done. Run this once to scrub those old passwords from every student and teacher record. Logins and resets are unaffected.

📄 Upload Chapter Material

Upload PDFs or images for chapters. Students will see them in their dashboard.

Students will see this PDF only on the matching sidebar tab.

Regular = visible to all students of this class. Foundation / JEE / NEET = visible only to students enrolled in that type.

Show this chapter only to students of the chosen board. The Subject above is matched against each student's enrolled subjects automatically.

How: Open file in Google Drive → Right-click → Share → “Anyone with the link” → Copy link
